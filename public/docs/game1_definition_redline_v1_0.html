1. ゲームの核・設計原則

Game1は、プレイヤーと敵が同じ盤面に箱を投入し、能動投入された起点箱を基準としてリンクや形成立を起こし、HPを削り合う対戦型パズル・ローグライクです。箱は攻撃成立時に自動消去されず、過去の配置がその後の攻撃・妨害・盤面構築へ残り続けます。

プレイヤーと敵は同じ盤面を共有する。

基本操作はタップ／クリック。複雑な回転・ドラッグ操作を必須にしない。

攻撃成立後も箱はその場に残る。盤面を消すには盤面スキル等の別手段が必要。

基本は交互手番だが、追加手番などによる連続行動を許す。

【ver1.0 補足】追加手番は未実装。手番開始のボーナス投入は、独立した追加手番ではなく同じ手番内の能動投入。

基本勝利は敵HP0、基本敗北はプレイヤーHP0または新規箱を合法投入できない状態。特殊勝敗条件を追加できる。

【ver1.0 改訂】基本勝利は敵HP0以下、基本敗北はプレイヤーHP0以下。合法投入不能だけでは敗北しない。PvEの行動選択・スキップ・敵の即死相当攻撃は5.5の改訂に従う。

キャラクターの強さは数値だけでなく、基本攻撃、盤面スキル、通常スキル、変化、回復アクセスなどの組合せで表現する。

敵は単なるランダム妨害ではなく、行動パターン・専用スキル・予告・配置AIによって攻略対象として個性を持つ。

放出点を介さず、指定位置などへ箱を新たに作る処理。原則として能動投入とは扱わない。

手番

プレイヤーまたは敵が行動できる機会。

行動権

その手番で通常行動を1回実行できる権利。

通常行動

箱を能動投入する、または盤面スキルを使用する行動。原則として行動権を消費する。

【ver1.0】ver1.0の通常行動は投入・固有盤面スキル・装備した消耗品のいずれか1回。

追加手番

通常の交互手番を超えて、同じ主体が続けて得る次の手番。

即時行動

行動権を消費せず、その場で実行できる処理。即時発動スキル等で使用する。

行動終了

その主体の当該手番における行動処理が完了した状態。

戦闘不能

HP0等の敗北条件を満たし、その戦闘で行動できなくなった状態。

連結

同じ所有者の箱が一直線上に連続して存在している、盤面上の静的な状態。

リンク

能動投入された起点箱を含めて、同じ所有者の箱が一直線上に規定数以上連結したことで成立する判定。

リンク数

成立したリンクを構成する、一直線上の連続した同一所有者箱の数。

形

箱の相対位置によって定義される特定の配置パターン。盤面上に存在する静的な配置概念。

形成立

能動投入された起点箱を含めて、定義された形が完成したことで成立する判定。

基本攻撃

キャラクター／敵が標準で持つ、スキルスロット非依存の攻撃能力。

スキル

ゲーム中に装備・使用・発動する能力の総称。大きく「盤面スキル」と「通常スキル」に分かれる。

盤面スキル

通常行動として箱の能動投入に代えて使用し、盤面へ直接干渉するスキル。基本2枠（固有1＋自由1）。

通常スキル

盤面スキルとは別の通常スキルスロットへ装備するスキルの総称。初期装備上限は3枠で、ラン中に拡張可能。

【ver1.0】固定初期1枠＋自由2枠。固定枠は交換不可、同名報酬で＋化可。枠拡張は将来。

リンクスキル

リンクの方向・リンク数等を発動条件に含む通常スキル。能動投入後に条件を満たすと自動的に発動対象となる。

形スキル

特定の形成立を発動条件に含む通常スキル。能動投入された起点箱を含む形だけを判定する。

即時発動スキル

プレイヤーが任意のタイミングで使用する通常スキル。スキルごとに有限の使用可能回数を持ち、原則として行動権を消費しない。

【ver1.0】有限回数の任意使用能力。今回の消耗品は通常行動を消費し、使用後に消滅する。

パッシブスキル

通常スキルスロットに装備し、現在の盤面・状態等を継続的に評価して効果を適用するスキル。任意の発動操作を必要としない。

発動対象スキル

能動投入後の判定で発動条件を満たし、その一手で効果処理されることが確定したリンクスキル／形スキル。

使用可能回数

即時発動スキルをそのラン中に使用できる総回数。スキルごとに個別設定する。

残り使用回数

即時発動スキルがあと何回使用できるかを表す値。使用ごとに1減り、0になるとそのスキルは消滅する。

変化

十分な変化ゲージを持つ状態で、能動投入による6リンク等の条件を満たした際に最優先で発生するキャラクター固有の特別システム。

【ver1.0】能動投入の形・リンク攻撃後、6以上・必要ゲージ・双方生存・非変化中なら自動発動。

変化ゲージ

変化の発動準備に使う蓄積リソース。手番経過・リンク・通常スキル等、キャラクターごとに獲得源を設定できる。

変化可能状態

変化ゲージがそのキャラクターの発動必要量以上まで蓄積している状態。これだけでは変化は起こらない。

オーバーゲージ

変化の発動必要量を超えて保持している変化ゲージ。

オーバーチャージ

変化の発動必要量を超えて変化ゲージを蓄積すること。

戦闘

1体の敵との戦闘開始から決着まで。

ステージ

1回の戦闘を中心とした一本道ラン内の進行区間。

ラン

ゲーム開始からゲームオーバーまたは最終ボス撃破までの一連の攻略。

【ver1.0】ver1.0標準は開始からプレイヤー敗北までのエンドレス攻略。

継承段

ステージ終了時、盤面上部から探索して最初にプレイヤー箱が見つかる行。次戦へ持ち越す1段。

箱は「一番下の空きマス」に直接置かれるのではありません。放出点から指定された初期方向へ進み、障害物等にぶつかった後は貼り付かず、重力方向へ落下します。横から射出するギミックも可能ですが、最終的には重力に従って安定位置へ落ちます。

3.4 箱は自動では消えない

リンクや形成立によって攻撃しても、その箱は盤面に残ります。箱を消すのは盤面スキル、箱タイプ固有処理、敵行動など別の明示的な効果だけです。箱を消した結果、上側に空間ができた場合は残った箱を重力方向へ落として詰め直します。

重要 破壊後の再落下などの受動行動で新たな3連結・6連結や対象形状ができても、それはリンク／形成立ではありません。基本攻撃・リンクスキル・形スキル・変化は新規発生しません。

4. 箱データ・箱タイプ

4.1 所有

箱の現在所有者は、箱を最初に置いた者とは独立して変更可能です。プレイヤー箱・敵箱・中立箱を持ち、能力によって所有権を書き換えられる余地を残します。

4.2 所有・種類・状態は別属性

箱は少なくとも「ownerId（所有）」「typeId（種類）」「stateId（状態）」を別の情報として持つ設計にします。したがって、プレイヤーのマグマ箱、敵のマグマ箱、中立のマグマ箱のような組合せも表現できます。

├─ typeId : NORMAL / MAGMA / RUBBLE / ...
└─ stateId : NORMAL / FROZEN / ...

5. 手番・能動投入・一手の処理

5.1 手番と先攻

通常はプレイヤー先攻で、プレイヤー手番と敵手番を交互に進めます。ただし追加手番などにより同じ側が連続して行動できます。また、「奇襲」のようなイベントでは敵先攻を許可します。

5.2 能動投入と受動行動

盤面上の箱・盤面変化は、判定上「能動投入」と「受動行動」に大別します。基本攻撃、リンクスキル、形スキル、変化を新規発生させられるのは、原則として放出点から箱を能動投入した場合だけです。所有権変更、既存箱移動、直接生成、破壊後の重力落下などの受動行動では新規発生しません。

ただし、能力の説明に「放出点から箱を放出する」「能動投入として扱う」と明記された効果は例外的に通常の能動投入と同じ判定を行えます。

5.3 発動対象スキルの確定

能動投入された箱の配置確定直後の盤面を基準に、発動条件を満たすリンクスキル／形スキルを「発動対象スキル」として先に確定します。前のスキルが箱を消しても、すでに発動対象となった後続スキルの成立は取り消しません。空間的な発動条件はスナップショットで固定しつつ、攻撃力バフなどの数値状態は順次更新され、後続スキルへ反映されます。

【ver1.0 補足】現在の自動形・リンク能力は箱を消さない。盤面を変える自動能力を追加する際の成立スナップショットの一般仕様は将来拡張として残し、攻撃前変化の根拠には使わない。

例 スロット1が攻撃力+20、スロット2が攻撃の場合、スロット2は強化後の攻撃力を参照します。一方、スロット1が箱を消しても、着地直後に成立済みだったスロット2の形条件は失われません。

発動対象スキルは通常スキルスロット順に効果処理し、プレイヤーはスロットの並び順を変更できます。攻撃力バフ→攻撃など、順番自体がビルド要素になります。即時発動スキルはプレイヤーの任意使用、パッシブスキルは継続評価のため、この発動対象スキル一覧には含めません。

【ver1.0 改訂】所持スキル順で形スキルを先に解決し、その後に縦・横・＼・／の順でリンクの攻撃を解決する。形フェーズとリンクフェーズを混ぜない。数値の更新は後続効果へ反映する。ver1.0では自由なスロット並べ替え操作は未実装。消耗品は自分の通常行動として任意使用し、パッシブは定義した機会に評価する。

回復能力を持たない基本状態では、失ったHPは原則そのまま次戦へ持ち越す。

キャラクターごとに回復へのアクセス方法を変えられる。

変化の効果として「ラン中、毎ステージ一定量回復」なども可能。

8.3 HP継承と回復ライン

HPは完全持ち越しです。標準のステージクリア回復はありません。回復が多いキャラクター、変化で毎ステージ回復の加護を得るビルド、将来のメタ強化で少量回復を得るなど、回復そのものを設計価値として扱います。

8.4 将来の事前強化（メタ進行）

プロトタイプ必須ではありませんが、死に戻り後に恒久的なパッシブ強化を解放するスキルツリー的な仕組みを将来導入する余地を持たせます。例：ステージクリア時の微回復、初期最大HP、最大オーバーゲージ枠の拡張など。最大オーバーゲージの最終強化上限にはキャラクター差を持たせる案があります。

【ver1.0 補足】本項は将来のメタ進行。報酬のラン中火力は再開始で戻り、ランを超えて保存されない。

付録C 共通ルールとデータの境界

2026年10月1日の文書分離改訂。共通定義は本書、個別データの正本は別冊 Player Skill Monster カタログ、操作・検証・調整手順はver1.0ガイドとする。個別名称の変更や新規レコードの追加だけでは本書を長くしない。原本の将来構想は実装済みと区別して保持する。

C1 型と参照

Playerは初期HP・基本攻撃表・固定初期Skill・固有盤面Skill・変化効果・ゲージ設定を参照する。Skillは分類・発動機会・対象・効果順・値・tier・回数・装備規則・持続範囲を定義する。Monsterは初期HP・基本攻撃表・行動パターン・配置AIを参照する。表示名はIDと分離し、改名でIDを変更しない。

カタログは player.<id>、skill.<id>、monster.<id>を安定参照に使う。変化など通常枠に装備しない効果もSkill節の専用レコードで管理し、盤面枠・通常枠と混同しない。ラン設定と反復報酬は同冊の補助レコードとする。この表記は文書間参照であり、現行コードへ新しいデータ形式を実装したという意味ではない。

C2 効果と数値の共通契約

効果は小さな処理の順序付き組合せとして記述する。HP損失、HP回復、対象抽選、箱破壊、所有権変更、修正値の更新を分離する。自己費用で処理主体が戦闘不能になった時は後続を中断する。同時ダメージは両者の値を先に確定し、PvEで双方が倒れた場合はプレイヤー敗北とする。

回復は「設定された回復量」と「上限まで実際に回復した量」を区別する。回復を契機とする別効果がどちらを参照するかは個別Skillに明記する。既に解決した回復へ、後から発動した変化の効果を遡って付けない。

基本攻撃の基礎値、ラン中の永続加算、ステージ内だけの成長、当該軸だけの攻撃補正を別々に保持する。後続処理はそれまでに更新された数値を読む。上限・費用・係数・個別閾値はカタログまたは試験設定を参照し、効果関数の処理順へ埋め込まない。

C3 能動投入と手番開始効果

通常投入と、能動投入を行うと明記されたボーナスは、共通の起点生成・形判定・方向別リンク解決・ゲージ・変化判定を使う。形は種類ごとに1投入1回、所持順で解決し、基本攻撃の方向を抑制しない。その後、縦・横・＼・／の最大リンクを各軸1回解決する。

形の定義は必要マスの相対座標を持ち、特記がなければ90度単位の回転を許可する。向き固定ならその旨を表示する。新しい起点は必要マスのどこにあってもよい。鏡映は回転と別。必要マス外の空き条件は、明記された場合にだけ要求する。具体的なセル図と回転差分はカタログに置く。

手番開始の無料投入は通常行動権を残し、独立した完了手番には数えない。合法先なしの場合、消費する開始機会や副作用は個別効果の契約で定義する。ボーナスで敵を倒したら報酬待ちへ進み、旧ステージの通常行動を実行しない。持続は残り開始回数と通常行動終了を区別して管理する。

C4 変化とゲージ

能動投入の形と全リンク攻撃を終えた後、起点を含む条件リンク・必要ゲージ・双方生存・非変化中を確認する。現行の共通リンク条件は6以上。敵を倒した投入では変化せず、費用を使わずゲージを次戦へ持ち越す。手番終了のゲージ獲得で直前の投入へ遡って発動しない。

条件を満たす各リンク軸は実箱数を基準に1回だけゲージを得る。基本攻撃がスキルで置換されても獲得の二重化や取消をしない。HP損失の獲得は実損失を使い、自己費用を含み過剰ダメージを含まない。閾値を超えても減速せず上限まで加算し、変化中も獲得するが再変化はしない。

持続範囲はステージ・ラン・残り機会などを個別定義する。ステージ境界では設定に従い終了または引継ぎする。残り開始機会が0の期限付き効果を、撃破時の境界処理で次の手番へ延長しない。

C5 ビルド 報酬 継承

通常枠は固定初期1＋自由2。固定枠は同名の＋化が可能で入替不可。空き自由枠へ新規取得し、満枠なら自由枠の入替先を選ぶ。所持中の通常版の重複取得は同枠で＋1、所持中の＋版は候補から除外。未所持になった後の再取得は通常版。消耗品も自由枠を使い、今回の1回消耗型は通常行動を消費して枠を空ける。

撃破ごとに互いに異なる報酬候補を1回保存し、1つ取得またはスキップする。候補数とプールは設定を参照。再描画や入替取消で再抽選しない。報酬乱数は戦闘乱数と分離する。報酬待ち中は通常行動、次敵の設定、手番開始効果を停止する。

報酬確定後、現在HP、現在所有の自箱を含む最上位の横1行から自箱のみ、装備とtier、未使用消耗品、ラン中火力、ゲージ、持続条件を満たす効果を引き継ぐ。列を保ち同じ固定地形内で受動落下する。撃破だけの無料回復はなく、ステージ成長・敵周期は戻す。継承から形・リンク・変化を新規発動しない。
