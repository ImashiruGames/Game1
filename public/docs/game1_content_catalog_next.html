出発と、報酬を受け取るタイミング

  1. 所持キャラのカードを1回タップして切り替え
  2. 「経験値ツリー」「盤面スキル」「選択スキル」で次のランを準備
  3. 「ラン開始」で構成を固定して出発。進行中のランは「続きから」で再開

正式ランの終了時に、記録された撃破1体につき5コイン・そのキャラの10EXPを一度受け取ります。敗北でも撃破分は残ります。50階を生存してクリアすると毎回200コイン・250EXPを追加し、合計450コイン・750EXPです。

続ける / 帰還する

ホームを開いただけではランは終わりません。「帰還する」は、キャラ・撃破数・報酬を確認して終了する別の操作です。正式ランなら撃破分を受け取れます。0体なら0。途中の敵へのダメージは数えず、クリア追加報酬・クリアトロフィーは付きません（新規ラン中に達成したダメージ・最大HP実績は保持）。

帰還できるのは、自動処理が終わった自分の行動選択中だけです。報酬を確定・スキップした後も、赤の追加投入などの解決は省略しません。キャンセルすれば続けられます。帰還後はそのランを再開できず、新しいランも自動では始まりません。

検証ランや正式出発の記録がないランは精算対象外です。記録のない過去のプレイへ遡って報酬・トロフィーを付けることはありません。

今回の操作変更

戦闘画面の上に「速度 通常／短縮」を常設しました。次の行動から反映し、設定はこのブラウザに保存します。端末またはゲームの動き低減が有効な場合は「低減で短縮」と表示し、安全のため低減設定は維持します。音はベルのSE＝効果音、音符のBGM＝音楽。斜線とOFF表示で停止状態を示し、別々に切り替えます。歯車で音量と演出を調整できます。戦闘ログは設定内の専用ボタンで開きます。速度ごとに投入・着弾・HP表示・技の終わりを同期し、技の表示が終わる前に次の手番へ進まないようにしました。

ホームの出発ボタン上でBGMのON/OFFと音量を調整できます。設定はステージと共通で、出発・帰還・ボス戦で曲だけ切り替わります。BGM設定はこのブラウザに保存されます。保存したONも、ページを開き直した後は「再開」をタップするまで鳴りません。効果音は別設定です。

  • ラン開始でHP・火力・持ち込み構成を確認してから出発します
  • 所持スキルは盤面下の小さなカードに常設。形やリンク数のアイコンをタップするとカードを開き、即時発動スキルはそこから使用できます
  • ガチャはハンドルからカプセルが出る演出へ。閉じても抽選と残高は保存され、結果は変わりません
  • 投入点は各盤面の実際の辺に表示。内部天井も扱い、大きな盤面は盤面領域だけスクロールできます

経験値エナジー

ホーム右上の✧から使用できます。1個＝50EXP。成長途中の所持キャラに使うと、その場でキャラのEXPに加算します。上限をまたぐ分も全量保存しますが、上限到達後のキャラには使えません。たとえば750EXPから3個使うと900EXP、Lv9になります。全キャラが上限なら、現時点ではエナジーの使用先はありません。

以前の高いレベル・獲得ポイント・EXPは保持します。現在のツリーで使えない旧ポイントは記録として残り、画面には割り振れる残りポイントだけを表示します。今の上限を超える強化や将来の使用を保証するものではありません。

所持品・選択スキル・装備枠は別

  • 選択スキルはラン中のスキル報酬に出す候補。使用可能な6〜20種類を選び、出発時に固定します。トロフィーを含む全所持時の候補は青35、ほか34種類です（選択できるのは最大20種類）
  • ガチャで得たスキルは所持品に追加されます。使いたいキャラのプールに手動で加え、ラン中の報酬で選びます。自由枠に最初から装備されるわけではありません
  • スキル報酬は最大3択。＋を所持中のスキルは外れるので候補が減る場合があります。強化が済んだ構成では入れ替え候補だけになることもあります
  • ヘルスは青の固定スキル専用。ほかのキャラの候補・自由枠には入りません。毒盛り術はバイオレット固定で、通常報酬・ガチャ・＋強化の対象外です

敵の種類と出現階層

v1.10の新しい50階ランでは、階層ごとに異なる候補から敵を抽選します。同じシード・同じ階数なら同じ敵です。抽選は戦闘中の乱数や報酬の抽選に影響しません。以前の保存ランは最後まで旧出現順を維持します。

  • 1–24階：マルジロ（重み3）、ヒキキザン（重み2）、メラルン（重み2）、ツインコア（重み3）、ニードルコア（重み2）
  • 26–39階：ニギリン（重み2）、フロストコア（重み3）、ソーンコア（重み3）

1–24階は通常投入と基本リンク攻撃だけ。26–39階で回復・氷結・トゲを1種類ずつ学び、41–49階では上位の氷結・トゲに加え、正確な4連で毒を付けるデビルモンと、高火力の通常投入型シャシャークが出現します。複数のギミックを一体へ重ねていません。25・40・50階は抽選より優先される固定ボスです。

定義書とモンスターデータの分け方 / Definitions vs monster data

共通定義書は「リンク、能動投入、手番終了、1箱1タイプ、フローズン、トゲ、KO後の停止」の意味を定義します。モンスターデータはその定義を参照し、ID・名前・HP・攻撃表・行動周期を記述します。出現階は別の出現表で範囲と重みを管理し、ボスだけ固定上書きします。

Common definitions own the meaning of links, insertion, turn-end effects, single box types and KO boundaries. Monster data supplies identity, stats and behavior parameters. Separate encounter bands own stage ranges and weights; fixed bosses override random pools.

各モンスターへ1–24など全階の配列を埋め込む方式は採用しません。新しい敵は再利用できる定義を追加し、必要な帯の候補へIDを参照させます。例外は固定ボス表へ追加。出現表の変更時は新しい版を作り、保存ランの版を変更しません。

Do not repeat every floor inside each monster. Add a reusable monster, reference its ID in a weighted band, and use explicit overrides for fixed encounters. Publish a new encounter version for changes; saved runs keep their original version.

1箱に1タイプ。付与は上書き

所有者とタイプは別です。敵箱を自箱へ捕獲してもタイプは残ります。タイプの上書きや受動落下だけで、新しいリンク・形は発動しません。

輝き
そのリンク・形に1個以上含まれると、そのリンクのダメージとゲージ獲得、またはその形のダメージと回復量が2倍。複数でも重複しません
フローズン
リンクに1個でも含まれると、そのリンクの攻撃力が半減します（小数点以下切り捨て）。複数でも半減は1回。このリンクの攻撃後、含まれるフローズンは通常タイプへ戻ります。後のリンクでは通常通りです。輝き・リンク補正の後、防御の前に計算し、形状スキル・回復・ゲージには影響しません。 既存の保存ランは従来の1個につき−1を維持します
絶対零度
リンク攻撃力を半減し、攻撃後も溶けません。フローズンと合わせても半減は1回です
どく / げきどく（もうどく）
所有者の全手番終了時、所有箱1個につき基礎1 / 2ダメージ。毒盛り術は自分が付与した箱にだけ現在の自箱2×2の数を加算します
ガレキ
重力と反対方向の直上に2箱以上積まれると崩れます。再落下は受動で、リンク・形を発動しません
トゲ
既存トゲの周囲8マスへ能動投入した直後、投入者に最大HPの2%ダメージ。トゲ1個ごと切り捨て・最低1が現在の丸めです。形・リンクより先に処理し、受動落下や変換では発動しません

50階までのボス

25・40階にスピードコア、50階にマザーコア。スピードコアは自身5手番ごとに固定3ダメージの後で投入します。マザーコアは投入4手→待機1手→2回投入2手。HP20%以下に入ると次の敵手番から固定5＋投入→投入の2手周期です。2回投入は順に解決し、途中でKOなら残りは中止します。

音は初めOFF。効果音とBGMは別々に開始・停止できます。ホーム専用Starlight Terminal・通常曲・中ボス曲・マザーコア曲が画面に合わせて切り替わります。新しい6キャラの変化音は現在、既存の赤の変化音を共用しています。

  • 正式ラン中の最大HPが100以上に到達 → 救急箱
  • このキャラで正式ランを1階から50階までクリア → 澄んだ支柱
  • このキャラで正式ランを1階から50階までクリア → 挟撃

  • このキャラで正式ランを1階から50階までクリア → 四拍子
  • このキャラで正式ランを1階から50階までクリア → 輝き継ぎ

実ダメージは1回の自手番の追加投入・複数軸・形・直接攻撃を合算し、過剰ダメージと敵手番中の毒を除外します。解放は自動装備ではなく、次の出発用プールへ手動で追加します。進行中の候補は変わりません。大振り攻撃は5以上リンクへ現在の5リンク火力の50%（＋100%）を追加し、端数切り捨て。救急箱は上段が自箱・任意・自箱、下段が自箱3個。回転不可、任意マスは空・敵箱も可、基礎10回復・＋なし。輝き・青の既存回復連動は通常通りです。
