一画面で戦うための配置案

これはタップ操作と配置を試す画面案です。実ゲームの戦闘・HP・所持品は変更しません。

  • CSS Gridで上部情報・演出・盤面・下部操作を分けます
  • 縦持ち、6×8の盤面。短い画面では余白と上部だけを詰めます
  • 行スキルの選択中も盤面は隠しません。下のボタンが取消／確定に変わります
  • 詳しい説明とログだけ別画面。戻ると元の盤面です
  • 投入の二度タップは提案です。正式版へはまだ反映していません

基準：iPhone 14 /16e /17e級の小さい画面を想定。390×640はブラウザのバーを考慮した設計上の検査枠で、すべてのSafariの実測値ではありません。

Apple：iPhone 14の仕様 · WebKit：小さいビューポート

設計メモ

端末の画面全体と、Safariの中で使える領域は別です。標準の小画面クラスを390 CSS px幅として設計し、高さ640／600でも盤面・HP・操作を同時に見られるかを試します。実機Safari、表示拡大、文字拡大は別途確認が必要です。全面を100svhで配分し、セーフエリアを確保します。盤面の正方形セルは残り高さから計算するため、短い画面では横幅いっぱいには広げません。

ゲームロジックやスキル評価とは独立した画面案です。上部のキャラクターと演出は位置確認用。選択対象は画面を覆うウィンドウを出さず、盤面上で色を変えて表示します。
